# Contributing to Dream Download Manager

Thanks for wanting to help. Bug reports, ideas and code are all welcome.

## Reporting a problem

Say what you did, what you expected, and what happened instead. For a
download that fails, include the kind of site (don't share private links) and
what the app showed. Screenshots help.

## Sending code

- Keep each change to one thing, and explain why it's needed.
- Run the tests (`go test ./...`) and say how you checked your change.
- Follow the style around you: plain names, comments that explain why.
- Don't copy code from projects whose licence doesn't allow it (for example,
  closed-source download managers), and don't add trackers or ads.
